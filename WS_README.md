# Agent Bricks Workshop

## What this is

A hands-on workshop where you build an AI assistant on Databricks, one piece at a time.

Everything around you is already prepared — the data, the documents, the systems, the mailbox.
You build the agent.

You start with something that can answer one narrow question. You finish with an assistant that
can take a messy, real-sounding problem and work through it end to end.

## The scenario

You work on the support desk at **Saldo**, a cloud accounting and payroll platform used by a few
hundred companies.

On Tuesday, **Alpine Retail** ran their monthly payroll. 47 employees didn't get paid. It's
month-end, their finance director is furious, and she's certain it's our fault.

Work out what actually happened — is it only them or is everyone affected, is this on us, and do
we owe them anything? Then update the case and get back to her.

Today you'd answer that by hand, across six different systems. By the end of the workshop you'll
have built something that answers it from a single question.
