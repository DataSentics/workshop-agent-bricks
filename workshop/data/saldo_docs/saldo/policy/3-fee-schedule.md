## 1. Subscription

The plan sets availability, support hours and which channels are available. Modules are
subscribed separately and billed on top.

| Plan | Base monthly charge |
| --- | --- |
| Standard | 3,900 |
| Professional | 11,800 |
| Enterprise | 39,500 |

## 2. Modules

| Module | Charge |
| --- | --- |
| Bookkeeping | Included in the base charge |
| Invoicing | 1,900 per month |
| Banking | 1,400 per month, per connected bank |
| Tax | 2,900 per month |
| **Payroll** | **Per active employee, see below** |

Payroll is charged monthly in arrears on the number of active employees in the employee master
on the last day of the month.

| Plan | Per active employee / month |
| --- | --- |
| Standard | 39 |
| Professional | 59 |
| Enterprise | 79 |

An employee is *active* if they have a current contract and were eligible for at least one
payroll run in the month.

## 3. Payroll runs

| Item | Charge |
| --- | --- |
| Scheduled monthly run | Included |
| **Correction run, same pay period** | **Included** |
| Off-cycle run, additional pay period | 2,500 per run |
| Expedited processing (same-day value) | 4,000 per run |
| Run cancelled after submission | 1,500 |

A correction run is a run that pays only employees who were rejected or failed in an earlier
run for the same pay period. There is no limit on the number of correction runs within a pay
period, and they are not charged.

## 4. Data services

| Item | Charge |
| --- | --- |
| Bulk employee import | Included |
| Employee data template prepared by support | Included, on request |
| Historical data export | Included |
| Custom report development | 12,000 per report |

## 5. Support

| Item | Charge |
| --- | --- |
| Support within the plan's hours | Included |
| Out-of-hours support, Standard and Professional | 6,000 per incident |
| Named contact | Enterprise only, included |
| On-site assistance | 25,000 per day plus expenses |

## 6. Credits and adjustments

Service credits arising under the *Service Level Agreement* (SALDO-DOC-0040) are applied
against the next invoice. Credits are never paid in cash and never exceed 25% of the monthly
fee for the affected month.

Goodwill adjustments offered by an account manager are recorded separately from service credits
and require approval as follows:

| Value | Approval required |
| --- | --- |
| Up to 10,000 | Account manager |
| 10,001 – 50,000 | Head of Commercial |
| Above 50,000 | Finance Director |
